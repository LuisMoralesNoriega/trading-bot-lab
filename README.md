# Trading Bot Lab

This repository contains the evolution of a Python-based trading bot project focused on crypto market analysis, trend detection, and buy/sell readiness signals.

## Project Structure

- `v1/` - Initial prototype and base logic
- `v2/` - Improvements and adjustments
- `v3/` - Extended analysis logic
- `v4/` - Additional trading signal improvements
- `v5/` - More structured version
- `v6/` - Latest version with trend analysis and trade logging

## Features

- Crypto market trend analysis
- Bullish and bearish signal detection
- Buy/Sell readiness logic
- CSV-based trade logging
- Modular Python scripts
- Iterative project development from version 1 to version 6

## Tech Stack

- Python
- CSV processing
- Market data analysis
- Technical analysis logic

## Project Status

This project is part of my personal software engineering portfolio.  
It is an educational and experimental trading bot prototype.

This is not financial advice and should not be used for real trading without proper validation, backtesting, and risk management.
